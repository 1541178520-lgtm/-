# 高频档案编辑、品牌与 Word 导出设计

## 目标

在不引入年级科目模板等额外维护工作的前提下，让老师每天连续维护大量学生档案时减少点击、避免丢稿，并能一键导出排版稳定的 Word 成长档案。

## 品牌 Logo

- 使用用户提供的“创新学苑教育”图片作为唯一品牌素材，复制到项目 `public/brand/innovation-academy-logo.jpg`。
- 通过 CSS `object-fit: contain` 和受控容器显示，不修改原始商标图形或颜色。
- 登录页显示完整 Logo；学生目录顶部显示紧凑 Logo；Word 封面居中显示 Logo。
- 工作区内容页不重复大尺寸 Logo，避免干扰老师录入。

## 自定义成绩科目

### 数据模型

- 新增全局 `score_subjects` 科目表，保存唯一名称和创建时间。
- 初始化语文、数学、英语、物理、化学五个常用科目。
- 新增 `score_values` 表，使用 `(score_id, subject_id)` 唯一约束保存某次考试的科目成绩。
- 迁移现有 `scores` 表五个固定字段中非空的值到 `score_values`；保留旧字段以兼容迁移和回滚，但新接口以动态科目值为准。
- 删除某个全局科目不在本轮提供，避免误删历史成绩。科目创建后可复用。

### 操作

- 成绩表单默认显示五个常用科目。
- “添加科目”可以从全局候选中选择，也可以输入新名称；同名忽略大小写和首尾空格，不能重复。
- 一次成绩中没填写的科目不保存，不在时间轴和 Word 中显示。
- 编辑成绩时显示该记录已有科目和常用科目；清空某科目后保存即删除该次考试的该科目成绩。
- 分数范围保持 0 到 150，支持 0 和 0.5 步长。

## 晚辅与课程直接编辑

### 交互状态机

- 已存在记录的日期、课程内容和反馈直接渲染为输入控件，不再通过“编辑本页”弹窗。
- 输入后立即进入“未保存”状态；停止输入 800ms 或输入框失焦时触发保存；`Ctrl+Enter` 立即保存。
- 状态清晰显示为“未保存 / 保存中 / 已保存 / 保存失败，点击重试”。
- 保存请求期间继续输入时，不覆盖新输入；当前请求完成后若草稿已变化，再保存最新版本。
- 页面卸载时如果仍有未保存变化，用浏览器离开提示防止静默丢稿。
- 翻页、切换课程科目或切换学生前，控件先失焦并等待当前保存完成；保存失败则留在当前记录。
- 记录日期保存后按日期重新排序，并保持定位到刚修改的记录。

### 新建与删除

- 新建记录仍使用明确的“新增”按钮和表单，避免误生成空白记录。
- 删除仍保留确认步骤。
- 课程页面直接编辑日期、课程内容、教师反馈；晚辅页面直接编辑日期和反馈正文。

## Word 导出

### 用户流程

- 学生页原“打印档案”改为“导出 Word”。
- 点击后请求当前学生完整档案，浏览器下载 `.docx` 文件，不打开打印页。
- 文件名为 `学生姓名-成长档案-YYYY-MM-DD.docx`，对 Windows 非法文件名字符进行替换。
- 导出中禁用按钮并显示状态；失败时在原页面提示并可重试。

### 文档结构与分页

- A4 纵向，约 18mm 页边距，中文宋体/等线组合，品牌蓝橙作为有限点缀。
- 独立封面：Logo、学生成长档案标题、姓名、学校、年级、入学日期、标签。
- 成绩章节另起一页，表格列根据实际出现且有值的科目动态生成，未填写科目不出现。
- 晚辅章节另起一页，每条记录保持在同一页内；过长正文允许自然跨页，续页保持可读段落间距。
- 每个有内容的课程科目另起一页；空课程科目不输出。
- 页眉显示创新学苑教育和学生姓名，页脚显示自动页码；封面不显示页眉页脚。
- 文档由前端使用 `docx` 库生成，后端继续提供结构化档案 JSON，不在 Worker 中拼二进制文档。

## 高频工作流优化

- 学生标题区新增“上一名 / 下一名”按钮，顺序与左侧目录一致，切换时保持当前章节类型。
- 本轮不实现年级科目模板和全学生表格录入，避免维护负担和范围膨胀。
- 后续若老师需要同时填写几十名学生的同一日反馈，可单独设计“今日批量录入”工作台；它与当前档案阅读页应保持分离。

## 错误处理与兼容

- 动态科目、直接编辑和 Word 导出均使用现有管理员会话与同源保护。
- API 校验返回字段级中文错误；自动保存错误保留草稿，不回滚为旧值。
- 数据库迁移只新增表和复制数据，不删除旧列。
- 原 `/students/:id/print` 路由可重定向回学生档案，界面不再提供打印入口。

## 测试与验收

- Worker 测试：默认科目、创建自定义科目、重复约束、动态分数 CRUD、未填科目不返回、旧数据迁移结果。
- UI 测试：添加/复用自定义科目、清空删除值、直接编辑 800ms 保存、失焦保存、失败保稿、保存中继续输入、日期重排。
- Word 单元测试：解压 `.docx` 检查文档关系、Logo、章节、动态科目、空科目省略、分页符和页码字段。
- Word 视觉测试：生成包含多页成绩、10 条晚辅和三科课程的样例 DOCX，使用 LibreOffice 渲染全部页面并逐页检查。
- E2E：Logo 显示、自定义科目、直接编辑持久化、上一名/下一名、真实 Word 下载与文件非空。
- 最终门禁：类型、Lint、Worker/UI、Playwright、生产构建和依赖审计全部通过。
